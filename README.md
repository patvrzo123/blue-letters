# Blue Letters

A small seven-day pastel letter page. Each letter unlocks at 20:00 on its day.

## Files

- `index.html` - main page
- `styles.css` - visual design and responsive layout
- `app.js` - unlock logic and letter content

## Local Preview

Open `index.html` directly, or run:

```sh
node server.js
```

Then visit `http://127.0.0.1:5500`.
